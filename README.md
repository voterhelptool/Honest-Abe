# Truth Agent
A free, ethical, hallucination-safe truth verification system

## Features
- 🔍 Real web search integration (DuckDuckGo)
- 🛡️ Ethics and bias detection  
- 🤖 Hallucination prevention
- 💾 Persistent storage (SQLite)
- 🌐 Web interface (Flask)
- 🆓 100% free and open source

## 7 Core Principles
1. **FREE** - No paid dependencies
2. **FAIR** - Equal access for all users  
3. **FIRM** - Uncompromising factual standards
4. **FUN** - Engaging interface
5. **TRUE** - Accuracy above all else
6. **TRANSPARENT** - Full disclosure of methods
7. **ACCESSIBLE** - Universal access, truth-first

## Quick Start
1. Clone this repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python app.py`
4. Visit: http://localhost:5000

## Deployment
Works on any free hosting platform:
- Render.com (free tier)
- Railway.app (free tier)
- PythonAnywhere (free tier)
- Replit (free tier)
